# Contributing

Thanks for contributing to The Open Syllabus.

## Development workflow

1. Create a focused branch for the change.
2. Keep commits small and descriptive.
3. Keep secrets and local environment files out of source control.
4. Run the repository quality checks before opening a pull request.

## Quality checks

```bash
npm run lint
npm run build
```

## Pull requests

Describe the problem being addressed, summarize the implementation, and note any user-facing or engineering impact. Keep unrelated cleanup out of the same pull request.
